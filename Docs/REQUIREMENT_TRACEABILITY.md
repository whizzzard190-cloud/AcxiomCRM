# AcxiomCRM - Requirement Traceability Matrix (RTM)

This matrix maps every functional and non-functional requirement to its architectural components, security checks, tests, and current verification status.

| Req ID | Requirement Description | Module | Entity | UI (Razor Views) | API (Controllers/Api) | Service Layer | Server Validation | Authorization / Scope | Audit Event | Golden Tests | Status |
